# Identity Center

AWS IAM Identity Center (anciennement AWS SSO) est la porte d'entrée de toute une organisation : il associe les utilisateurs du personnel à des **jeux d'autorisations** dans les comptes membres. Le contrôle de ses affectations ou de son annuaire d'utilisateurs transforme un seul point d'ancrage en un accès à travers tous les comptes qu'il gère.

## Pages

- **[Jeu d'autorisations](permission-set.md)** : affecter ou modifier un jeu d'autorisations pour vous accorder un rôle dans un compte cible.
- **[Identity Store](identity-store.md)** : ajouter ou modifier des utilisateurs et des appartenances de groupe pour hériter de leurs accès.
