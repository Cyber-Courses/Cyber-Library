# Applications

**Applications** are deployable software that serves users or other systems. The tree separates **client**-side concerns (browsers, extensions, device apps) from **server**-side concerns (HTTP APIs, workers, and daemons that implement business logic).

## Server-side web stack

- **[Server](server/index.md)** — Server applications that expose interfaces and process data for clients.
- Under server, **[Web](server/web/index.md)** covers HTTP-oriented services.
- **[Code](server/web/code/index.md)** covers vulnerabilities in **application source** (what remains if you swap the web server and runtime for secure defaults but keep the same repository).
