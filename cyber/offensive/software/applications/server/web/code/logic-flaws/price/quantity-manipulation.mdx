# Quantity Manipulation

## Context

The purpose of this article is to equip attackers with the knowledge to exploit quantity manipulation vulnerabilities in web applications. This technique falls under the domain of logic flaws, specifically targeting applications that fail to validate or enforce expected quantity values. Key concepts include understanding HTTP request structures and web application logic, with a focus on quantity tampering techniques such as negative, zero, and cart quantity manipulation.

## Theory

### Quantity Manipulation in Web Applications

Quantity manipulation exploits logic flaws in web applications to alter quantities in transactions. These vulnerabilities occur when applications do not properly validate or enforce expected quantity values, allowing attackers to manipulate transaction outcomes for their benefit.

### Quantity Tampering Techniques

An attacker can modify quantity parameters in HTTP requests to alter transaction outcomes. By intercepting requests and adjusting quantity values, attackers can potentially gain unauthorized benefits or manipulate pricing and stock levels.

### Negative and Zero Quantity Exploits

Submitting negative or zero quantities is a technique used to exploit web applications. By doing so, attackers may gain unintended benefits, such as avoiding charges or bypassing restrictions that rely on quantity validations.

### Cart and Order Quantity Manipulation

Attackers can override quantities in shopping carts or orders to exploit pricing or stock. This manipulation can lead to altered transaction outcomes, such as reduced charges or unauthorized acquisition of goods.
